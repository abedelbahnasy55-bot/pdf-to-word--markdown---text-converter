# الأخطاء الشائعة وحلولها

## لا يوجد مفتاح Gemini

```
⛔ لا يوجد مفتاح Gemini.
```

الحل:

```bash
mkdir -p ~/.config/ocr
printf '%s' 'YOUR_KEY' > ~/.config/ocr/gemini_key
chmod 600 ~/.config/ocr/gemini_key
```

أو `export GEMINI_API_KEY=...` أو `--key-file path`.

## `429 quota` أو `RESOURCE_EXHAUSTED`

- **نفاد حصة الموديل** (20 طلبًا/يوم): المهارة تبدّل الموديل تلقائيًا.
  إن نفدت كل الموديلات: انتظر تجديد الحصة أو أضف موديلًا جديدًا في `--models`.
- **تجاوز معدل الدقائق** (رسالة فيها `limit=`): انتظر ثم أعد؛ لا تبدّل الموديل.

## «نصّ فارغ» من موديل

ليست بالضرورة نهاية الموديل: المهارة تعيد المحاولة 3 مرات قبل استبعاده.
إن تكرر مع موديل بعينه، أخرجه من `--models`.

## الصفحات المفقودة / الناتج قصير

- سبب شائع: قطعة كبيرة (36+ صفحة).
- الحل: `--chunk 6` أو دع إعادة المحاولة التلقائية تعمل.
- تحقق: `qa.json` يعرض `output_pages` مقابل `input_pages`.

## «CamScanner» أو أرقام صفحات في الناتج

نظّف مرة أخرى:

```bash
python3 clean_md.py raw.md clean.md --report clean.json
```

إن تكررت ترويسة لم تُحذف: ارفع نسبة التكرار أو احذفها يدويًا ثم أعد البناء.

## خطأ في LibreOffice عند بناء PDF

- أغلق أي نسخة LibreOffice مفتوحة إن تكرر الفشل.
- المهارة تستخدم مجلد مستخدم مؤقتًا؛ لا تحتاج إعدادات إضافية.
- تحقق يدويًا: `soffice --headless --convert-to pdf book.docx`.

## الخط يظهر بشكل مختلف

ثبّت Amiri:

```bash
sudo apt install fonts-hosny-amiri
fc-cache -f
fc-match Amiri
```

## العربية مقلوبة أو غير متصلة

- المهارة تضبط RTL على ثلاث طبقات (فقرة/run/نمط).
- تأكد أن النصّ المنظّف عربي فعليًا (وليست محارف مشوّهة) عبر `qa.json` (`arabic_ratio`).

## جداول مكسورة

- `qa_gates.py` يبلّغ عن الجداول ذات الأعمدة المتفاوتة.
- أصلح الجدول في `.md` ثم أعد `build_book.py` فقط (لا تعد OCR).

## العناوين لا تظهر

- المحرّك لا يخمّن العناوين؛ `clean_md.py` يرقّي العناوين المعروفة فقط.
- أضف يدويًا `##` قبل الأسطر التي تريدها عنوانًا، ثم أعد البناء.

## إعادة البناء بعد تعديل Markdown

```bash
python3 build_book.py clean.md book.docx --profile book --title "..." --pdf
python3 qa_gates.py --input original.pdf --md clean.md --docx book.docx --pdf-out book.pdf
```

## هل أستطيع تشغيل أكثر من كتاب بالتوازي؟

نعم، لكن الحصة مشتركة على مستوى المفتاح/الموديل. شغّل دفعات صغيرة
(كتاب أو اثنان) لتجنّب 429، ويفضّل `--mode auto` لتجاوز OCR للكتب الرقمية.
